Shop POS — Install & Help

The shop-computer version: runs on your Windows computer and works without internet, every day.

1. Install 2. Where the files go 3. Every day 4. Phones & tablets 5. Backups 6. New version 7. New computer 8. Problems

1. Install (one time, about 5 minutes)

You need: a Windows 10 or 11 computer, internet this one time, and the owner email + password from your website POS.

1

Download

Log in to your POS website → Settings → Install on shop computer → Download for Windows. You get a file named ShopPOS-Windows.zip in your Downloads folder.

If the browser says "isn't commonly downloaded": click … → Keep → Keep anyway.
2

Unzip it into C:\ShopPOS

  1. Open File Explorer (the yellow folder icon) → Downloads.
  2. Right-click ShopPOS-Windows.zip → Extract All…
  3. In the box, delete what's there and type: C:\ShopPOS
  4. Click Extract.
Don't run anything from inside the zip, and don't keep it in Downloads, on the Desktop or on a flash disk. The shop's data lives in this folder, so it must be a permanent place.
3

Run Install

Open C:\ShopPOS\ShopPOS and double-click Install (it may show as Install.bat).

Windows will ask a few questions. Answer like this:

Windows shows…You click…
Blue box: "Windows protected your PC"More info → Run anyway
(it appears because the file came from the internet)
"Do you want to allow this app to make changes to your device?"Yes
(lets phones in the shop connect)
Windows Security Alert about php.exeTick Private networks → Allow access
When it finishes, there's a Shop POS icon on the Desktop and the POS opens in your browser by itself.
4

Bring your shop over (or start new)

The POS opens on a setup screen. Choose one:

A) You already use the POS website — scroll down to "Or bring your shop over from the website" and fill in:

  • Website address — the address you open the POS with, e.g. https://your-pos-website.com
  • Owner email and Owner password — the same ones you log in with there

Click Import my shop and wait. A big shop can take a few minutes — don't close the page. Your products, stock, customers, sales history, staff and pictures are copied. Then log in with the same email and password.

B) A brand-new shop — fill in "Create the owner account" at the top (shop name, your name, email, password) → Create owner & finish → log in.

✓

Finished

From now on the POS works without internet. You can unplug the internet. Sales, stock, purchases, credit, payments, returns, expenses and reports all work.

2. Where the files go — and what they are

After unzipping, your computer has this folder. Yellow = things you use.

C:\ShopPOS\
└── ShopPOS\
    ├── Install.bat                 ← run ONCE to set up (shortcut, auto-start, phones)
    ├── Start POS.bat               ← starts the POS (the Desktop icon does the same)
    ├── Stop POS.bat                ← stops it (data is kept)
    ├── HELP - Read me first.html   ← this help
    ├── README.txt                    short version of this help
    ├── vc_redist.x64.exe             Microsoft program PHP needs (Install runs it if missing)
    ├── pos.ico                       the icon
    ├── data\                       ← YOUR SHOP'S DATA — never delete
    │   ├── pos.sqlite              ← all products, sales, customers…
    │   ├── backups\                ← a copy of pos.sqlite for each day (last 30)
    │   ├── logs\                     error notes (for whoever helps you)
    │   └── sessions\                 who's logged in
    ├── app\                          the POS program — don't change
    ├── public\                       the POS screens — don't change
    └── php\                          the engine that runs it — don't change
The only folder that matters for your business is data. Everything else can be replaced by downloading again. data cannot — so back it up (section 5).

3. Every day

  • Turn on the computer. The POS starts by itself (a small black Shop POS server window appears in the taskbar — leave it).
  • Open the POS: double-click Shop POS on the Desktop, or type localhost:8080 in the browser.
  • Log in and sell as usual.
  • End of day: just shut the computer down normally. (Or double-click Stop POS first — either is fine.)
Don't close the black Shop POS server window while working — it is the POS. If you close it by mistake, double-click Shop POS on the Desktop.

Tip: in the browser, press Ctrl + D on the POS page to bookmark it.

4. Phones & tablets in the shop

  1. The computer must be on and the POS running.
  2. Connect the phone to the same Wi-Fi as the computer. (The Wi-Fi router only needs to be switched on — no internet needed.)
  3. On the computer, open the black Shop POS window (or run Start POS): it shows a line like
    On phones/tablets on the shop Wi-Fi: http://192.168.1.20:8080/
  4. On the phone, open Chrome and type that address exactly. Log in as usual.

Tip: on the phone, Chrome menu ⋮ → Add to Home screen, so it opens like an app. If the computer's address changes after a router restart, read the new one from the black window again.

5. Backups — please read

All your shop's records are in one file on this computer: C:\ShopPOS\ShopPOS\data\pos.sqlite

  • Automatic: every day a copy is saved in data\backups (the last 30 days are kept).
  • But if the computer is stolen, burnt or the disk dies, those copies go with it. So once a week:
    1. In the POS: Settings → Backups → Download current data.
    2. Copy the downloaded file (e.g. pos-2026-10-09-1830.sqlite) to a flash disk, your phone, or email it to yourself when you have internet.

Restoring a backup (if something went wrong)

  1. Double-click Stop POS.
  2. Open C:\ShopPOS\ShopPOS\data and rename pos.sqlite to pos-old.sqlite.
  3. Copy your backup file into the data folder and rename it to pos.sqlite.
  4. Double-click Shop POS.

6. Installing a newer version (keeps all your data)

  1. Make a backup first: Settings → Backups → Download current data.
  2. Double-click Stop POS.
  3. Download the new ShopPOS-Windows.zip and Extract All to a temporary place, e.g. C:\ShopPOS-new.
  4. In the old folder C:\ShopPOS\ShopPOS, delete everything except the data folder.
  5. From C:\ShopPOS-new\ShopPOS, copy everything except its data folder into C:\ShopPOS\ShopPOS.
  6. Double-click Shop POS. Log in — all your products and sales are still there. Delete C:\ShopPOS-new.
Never copy the new data folder over the old one — that would replace your shop with an empty one. (If it happens: restore your backup, section 5.)

7. Moving to a new computer

  1. On the old computer: double-click Stop POS.
  2. Copy the whole C:\ShopPOS folder to a flash disk.
  3. On the new computer: paste it as C:\ShopPOS.
  4. Open C:\ShopPOS\ShopPOS and double-click Install (answer the questions as in step 3 of section 1).

Everything — products, sales, staff, logins — moves with the data folder.

8. If something goes wrong

What you seeWhat to do
"This site can't be reached" / "localhost refused to connect" The POS isn't running. Double-click Shop POS on the Desktop, wait 3 seconds, refresh.
Install opens and closes at once, or "VCRUNTIME140.dll was not found" Double-click vc_redist.x64.exe in the ShopPOS folder → Install → restart the computer → run Install again.
The Desktop icon is missing / POS doesn't start with the computer Run Install again (it's safe to run more than once; your data is untouched).
Phones can't open the address Same Wi-Fi as the computer? On the computer: Settings → Network & Internet → Wi-Fi → (your network) → Private network. Then run Install again and click Yes/Allow when asked.
Another program uses port 8080 (POS won't start, black window closes) Restart the computer. If it still happens, ask your technician (they can change 8080 in the .bat files).
Forgot the owner password The offline version can't send reset emails. Ask a staff member with access, or your technician, to reset it. Keep your password written somewhere safe.
"Import my shop" says the email/password is wrong Use the owner login of the website (not a staff login). Check the website address has no typo (try opening it in the browser first).
Anything else Send your technician the file C:\ShopPOS\ShopPOS\data\logs\php-errors.log and a photo of the screen.
